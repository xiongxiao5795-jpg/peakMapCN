# 微信小程序发布前的数据来源与事项核查

核查日期：2026-11-06。此文件记录当前原型的数据来源和公开资料，不能替代对具体产品形态、数据合同和监管要求的审核。当前项目没有提交或发布微信小程序。

## 当前联网来源

| 用途 | 当前地址与情况 | 部署位置和主要注意点 |
| --- | --- | --- |
| 卫星影像 | `server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/...`，Esri World Imagery；非小程序专用商业授权配置 | 境外运营方，CDN 节点可能变化，不能保证地图数据存储或请求均在境内。商业使用、客户端方式、署名、缓存和影像子来源的权利需按实际合同确认。 |
| 在线高程 | `tiles.mapterhorn.com`；默认中国概览已内置，放大时请求详情 | 国际服务，官方称使用 Cloudflare R2 和 Workers，不能保证位于境内；不同区域的上游高程来源和许可证不同。 |
| 道路、铁路、河流湖泊 | `tiles.openfreemap.org`，OpenFreeMap 托管的 OpenStreetMap / OpenMapTiles 瓦片 | 境外运营方，可使用 CDN；不能保证境内。OpenFreeMap 明示允许商业用途，但不免除 ODbL、署名及中国地图管理要求。 |
| 缺失行政区边界 | `geo.datav.aliyun.com`，阿里云 DataV GeoAtlas，已内置部分边界 | 阿里云服务；具体节点和存储位置应向提供方确认，不应仅根据域名断言。现有边界来源的商用、离线再分发授权尚未核实。 |
| 网页与内置文件 | 开发时本机 `0.0.0.0:4173`；正式部署尚未配置 | 正式小程序若使用网页容器，需要自行部署和配置域名；该本地地址不是公网发布地址。 |

地形概览、行政区名称索引、已收录边界、山地名称、太阳月亮计算和字体不需要在运行时访问上述外部数据服务；卫星、道路等图层、详细高程和缺失边界查询仍可能联网。点击资料署名等外部链接会访问相应网站。客户端请求瓦片会向提供方暴露请求所涉及的地图瓦片范围及网络连接信息，需要结合实际数据流和平台要求审视隐私政策。

## 许可与地图内容

- [Esri 服务条款](https://www.esri.com/en-us/legal/terms/web-site-service) 对非商业和商业使用分别设置条件；[Esri 内容许可说明](https://content.esri.com/arcgisonline/docs/tou_summary.pdf) 对离线、再分发和自托管有专门限制。[World Imagery 项目页](https://www.arcgis.com/home/item.html?id=10df2279f9684e4a9f6a7f08febac2a9)说明该图层不供直接导出瓦片离线使用。现有原型仅作测试，不能据此认定商业使用、卫星瓦片离线下载或转存有授权；应与 Esri 确认具体 World Imagery 服务、子来源、访问方式和目标平台，或替换为有明确授权的影像服务。
- [OpenFreeMap](https://openfreemap.org/) 页面明确表示允许商业使用，但要求署名，且数据来自 OpenStreetMap；[OpenStreetMap 许可](https://www.openstreetmap.org/copyright)要求注明来源及 ODbL，衍生数据库等还需要结合具体使用方式核查。OpenFreeMap 服务条款对离线下载数量、并发和标识有单独限制；其许可并不自动解决国内地图审核和位置合规。
- [Mapterhorn 数据来源](https://mapterhorn.com/attribution/)来自多个开放高程数据集。网页显示、裁切、打包和分发应逐一确认所覆盖地区的上游许可证及署名；已打包概览不等于取得地图审核批准。
- 行政区索引仓库声明 WTFPL，现有省级边界仓库声明 MIT；这些声明不自动证明其上游边界数据具备小程序商用、再分发或审图资格。DataV 提取的市、区县边界尚未确认再分发许可。[GeoNames](https://www.geonames.org/export)明确允许商业使用，数据使用 CC BY 4.0，需要署名、许可链接和适当标注处理变更。
- 当前地图使用示例边界裁切、公开数据和自行叠加的道路、标注，并未取得地图审图号，不能声称是标准地图。需要对底图、行政边界、岛屿、注记和新增图层组成的最终产品核查审核要求；直接沿用其他地图的审图号并不当然适用。

## 小程序与国内法规

- [《地图管理条例》](https://www.mee.gov.cn/zcwj/gwywj/202001/t20200114_759322.shtml)对依法使用审核地图、相关互联网地图服务资质及地图数据服务器等有规定。具体小程序经营主体是否属于互联网地图服务单位、需何种资质、哪些地图需要审核及更新如何处理，应根据实际服务方式咨询省级自然资源主管部门或有资质合作方。
- [自然资源部、工信部关于移动应用使用地图的通知](https://hnca.miit.gov.cn/zwgk/tzgg/tz/art/2024/art_270c90866b994bb69a020ce812de6278.html)对 APP 登载地图的审图、备案和标示等提出要求。该通知直接针对 APP；小程序的具体适用方式应结合其业务及平台审核规则确认，不应简单视为自动豁免。
- [天津市通信管理局答复](https://tjca.miit.gov.cn/jactpub/front/mailpubdetail.do?sysid=40&transactId=643267)指出其所述仅依托平台的小程序经营场景需备案，且特定条件下无需增值电信业务经营许可证；是否需要 ICP 经营许可要看实际业务及是否另有独立平台，不能因为收费或免费一概而论。
- 当前是 Vite 网页与 Android WebView，不是微信原生小程序。若采用 `web-view` 复用网页，需要依据账号主体和当期微信规则确认权限，配置和验证 HTTPS 业务域名，并完成要求的备案；[腾讯云的业务域名配置说明](https://cloud.tencent.com/document/product/1301/100434)说明了该场景。个人主体及海外主体是否可用应以微信后台最新规则为准。`web-view`、WebGL、Worker 和触控行为仍需在真实微信客户端验证；原生小程序不是直接复制当前网页即可运行。
- 即使使用境内服务器或标注“非标准地图”，也不能代替授权、地图审核、必要资质和隐私合规。建议先选定经营主体和产品形态，再与有资质的国内地图/影像服务商及当地自然资源和通信主管部门确认接入方式。
