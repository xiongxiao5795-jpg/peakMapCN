本次估算日期：2026-11-05。当前 v0.1.0 APK 为 1,649,691 字节，地图程序与少量示例地名已包含在 APK 内，但 Mapterhorn 高程瓦片仍通过网络加载。页面中的地形设色和坡面光照均由同一套高程数据计算，不需要额外再存一套底图。

采用项目 `data/china-provinces.json` 里的具名陆地区域合并后简化（0.01 度）作为估算范围，使用 Mapterhorn 发布的 `planet.pmtiles` 和 PMTiles 官方 CLI 的 `extract --region ... --maxzoom ... --dry-run`。结果是按范围相交瓦片估算的压缩归档体积，不是已经下载和安装的实际体积。不同时间数据更新、边界、压缩以及归档方法可能改变结果。

当前网页已接入 0–6 级中国概览：使用示例边界裁去范围外像素后，118 个内置瓦片共 12,309,112 字节，少于 22 MB；范围内的高程编码保持原值。详细层级仍联网按需请求，失败时回退放大的本地概览。其他高精度全国或区域离线包未实现，也不包含在内。

## 组合建议和区域增量

以下只是过去对不同范围的体积参考；当前方案仅内置小于 22 MB 的全国概览，不实现其他高程离线包。以下区域增量使用同一数据源的 `pmtiles extract --bbox ... --minzoom=9 --maxzoom=... --dry-run` 估算，表示在已有全国 0–8 级基础数据后补充的压缩高程归档大小，并非已下载的文件：

| 示例范围（矩形，非行政边界） | 仅补充 9–10 级 | 补充 9–12 级 |
| --- | ---: | ---: |
| 西安周边：东经 108.5–109.5°、北纬 33.8–34.8° | 2.7 MB | 22 MB |
| 林芝周边：东经 93–96°、北纬 28–31° | 27 MB | 255 MB |

例如，全国 0–8 级加上述两个 9–12 级区域的高程归档预计约 471 MB，加上程序、行政区边界等后体积会更大。区域大小、地貌、边界相交瓦片和数据源更新都会影响结果。最终下载量和设备占用需实际制作并在手机上测量；下载、导入或升级时可能需要额外的临时空间。

项目当前本地包含省级边界、行政区名称索引和约 4,799 个山地名称点；地市边界及 2,824 个区县边界已按省分包包含在网页构建中，索引中的另 154 个条目未获取到匹配的边界；离线分发的完整性和授权需要单独核实。太阳与月亮位置以及地形设色可由本地程序和高程数据计算，无需单独下载卫星影像。数据位置、清晰度和边界完整性不是正式地图保证。

## 在线参考图层初次流量样本
