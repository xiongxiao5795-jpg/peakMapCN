# 山河志 · 中国自然地理图鉴

探索中国的山脉、地形和行政区，用卫星影像和可调整的立体地形观察大地。

**[打开网页版地图](https://xiongxiao5795-jpg.github.io/peakmapcn-web/)** · 手机、平板和电脑均可使用

## 快速开始

1. 打开地图后，拖动地图浏览；用鼠标滚轮或双指捏合放大、缩小。电脑上按住鼠标右键拖动可旋转和倾斜；触屏上用双指旋转或同时上下移动来调整视角。
2. 点击左上角的放大镜，搜索地名或输入坐标，例如 `116.4074,39.9042`（经度在前、纬度在后），再选择搜索结果。
3. 点击左下角的定位按钮，并允许浏览器获取位置，即可查看所在地区；拒绝权限或定位失败时仍可浏览全国地图。
4. 打开右上角的“探索与设置”，在“地图”中切换卫星影像、地形设色和平面或立体视图，调整地形高度倍率。右下角的地图卡片也可以上滑选择倍率。

## 探索更多

- **行政区**：选择省、市或区县后，可在“边界”中开启“仅显示选中行政区”；关闭该选项可恢复完整地图。
- **光照与分析**：在“光照”中设置时间和光影，在“分析”中使用等高线、高程查询和地形剖面等工具。
- **鸟瞰与收藏**：左下角的鸟瞰图帮助查看当前位置；“探索与设置”中还提供收藏和分享功能。
- **地图操作**：左下角按钮可重置方向、缩放或返回全国视角；定位按钮单击查看省级范围，双击查看市级范围。

## 使用说明

地图需要支持 WebGL 的现代浏览器。卫星影像和详细地形依赖网络，初次加载或网络较慢时请稍候；定位需要允许浏览器权限和设备定位服务。内置全国概览可辅助显示，但网页版不保证完整离线使用。

地形高度倍率只改变视觉效果，不改变原始海拔；地形、地名和行政边界可能存在误差或遗漏，地图未经标准地图审核，不应用于导航、测量或专业判断。
