# 山河志 · 中国自然地理图鉴

这是一个用于先行验收交互的中国三维自然地理网页原型。它使用 MapLibre GL JS 与真实在线高程瓦片，不使用 Google Maps 或 Mapbox SDK。标签是独立维护的少量示例，并非完整或权威数据库；省级边界仅作原型展示，未经标准地图审核。Android 应用将在网页验收后另行制作。

## 启动

需要 Node.js 20.19+ 或 22.12+。在项目目录运行：

```sh
npm install
npm run dev
```

服务固定监听 `0.0.0.0:4173`，本机访问 http://localhost:4173 ，同一局域网的设备可通过 `http://<这台电脑的局域网 IP>:4173` 访问。网络及防火墙需允许访问该端口。生产构建：`npm run build`；预览构建：`npm run preview`。

## 操作

- 触屏：单指拖动地图；双指捏合缩放、旋转；双指同时上下移动倾斜；三指左右拖动旋转。
- 触控板：双指上下滚动倾斜，双指左右滚动旋转，捏合缩放；按住鼠标或触控板拖动平移。
- 鼠标：拖动平移，滚轮缩放；右键拖动可旋转和倾斜。地图右侧也有缩放、复位按钮。
- 浏览器通常不向网页暴露触控板的手指数；系统可能截获三指手势。不同设备的滚轮事件差异较大，触控板滚动与某些高精度鼠标滚轮可能无法完全区分。建议在目标设备上实测。
- 光照默认跟随当前时间，每分钟更新；使用北京时间（UTC+8）并按地图中心计算太阳或月亮方位和高度。白天显示太阳光，夜间月亮在地平线上时显示增强的月光；月亮也在地平线下时显示环境光。可手动选时、恢复当前时间并调整光影强度。光照设置或地图设置中可开关丁达尔光束，调整光束与光雾强度和高海拔增强；高海拔光雾基于真实高程进行不透明度分配。光束是屏幕空间的视觉模拟，不是实际体积光或山体投影；天空全景的光源位置也并非相机视野内的透视投影。
- 左侧可搜索或选择示例地点；地图设置中可控制中国范围、省级边界及各类标签；地图右下角可将地形高度倍率在 1×–80× 之间调整，默认 80×。倍率仅影响视觉高度，不改变显示的真实海拔。较大倍率会显著扭曲地形比例。右下角“鸟瞰地形细节”可选择标准、增强（默认）和精细：通过调整瓦片视觉尺寸，让同一视角使用更高层级的 DEM 和更密的地形网格。每提高一档，理想情况下瓦片数最多约增加至四倍；实际数量受视野、裁切和数据源最大层级限制，加载时间、流量和设备内存占用也会增加。源数据细节有限，最高层级后不会继续变精细。

- 顶部“布局”可选择自动、横屏或竖屏。竖屏使用底部搜索栏，地图右侧的光照和地形控件默认折叠。
- 地图上方天空全景示意按地图中心和选定时间计算太阳、月亮的位置，中央代表地图朝向、上下代表高度角；地平线下的天体不显示。该示意为 360° 全景，不是相机视野内的透视投影。

## 数据与限制

- 在线地形：[Mapterhorn](https://mapterhorn.com/attribution)，Terrarium 格式瓦片；高程数据来源及署名请查看其归属说明。地形起伏与分层设色均从同一数据解码生成，依赖访问该服务，并非离线数据包。服务可用性、许可和覆盖精度需要在正式部署前核实。
- `data/places.js` 是手工整理的示例地名与近似标注点，不代表山脉范围或行政边界。海拔和描述用于原型展示，正式发布前需核验来源与高程基准。
- 省级边界及中国裁切范围来自 [China-GeoData](https://github.com/Supeset/China-GeoData)，该仓库声明 MIT 许可，附许可文本见 `data/CHINA-GEODATA-LICENSE`。其上游数据授权、地理完整性及标准地图适用性尚需独立核实；该数据不得视为经过审图的正式地图。
- 默认仅请求与示例中国陆地区域相交的高程瓦片并在本地裁切；由于服务按瓦片提供数据，边界相交的瓦片可能包含范围外的数据。小岛及海域覆盖取决于示例边界数据。
- 暂未接入全量 OSM 地名、地形数据处理流水线、离线下载或安卓工程。公开发布涉及地图内容审核及数据许可，需要另行核验。
- 地图需要支持 WebGL 的浏览器；地形瓦片加载需要网络。国内网络访问第三方瓦片的效果请在实际网络中测试。

## 数据源配置

`src/terrain.js` 中的瓦片地址、裁切逻辑及 `src/main.js` 中的 `dem` 数据源构成高程输入。替换时需确认瓦片为 Terrarium 编码、跨域访问可用，并同步更新瓦片大小、最大缩放级别、署名与服务许可。分层色带见 `stops`。实际生产应将配置抽离并使用有明确服务保障的瓦片源。

## Android 安装包与固定签名

Android 使用 Kotlin 和 Android WebView，网页构建产物随 APK 打包；高程瓦片仍需网络，设备的 WebView 需支持 WebGL。支持横竖屏切换。应用 ID 为 `cn.peakmap.app`，Android 8.0（API 26）及以上可安装，实际兼容性取决于设备 WebView 与 GPU。

本地构建需要 Node.js、JDK 17、Android SDK 35，然后在项目根目录执行：

```sh
npm ci
npm test
npm run build
cd android
./gradlew assembleDebug
```

`assembleRelease` 必须设置 `ANDROID_KEYSTORE_PATH`、`ANDROID_STORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`，缺少时会失败，不会悄悄生成未签名的安装包。请安全备份签名密钥及密码；丢失后将无法用同一签名更新已安装的应用。不要把密钥或密码提交到仓库。

GitHub Actions 在推送到 main 或手动触发时构建经固定密钥签名的 release APK，验证签名并上传 `peakMapCN-signed-apk` 工件。签名所需的密钥和口令由仓库 Actions Secrets 提供，工件保留 30 天；它是供测试安装的构建，并不代表应用已完成上架或地图审核。
