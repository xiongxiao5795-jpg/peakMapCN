# 山河志 · 中国自然地理图鉴

这是一个用于先行验收交互的中国三维自然地理网页原型。它使用 MapLibre GL JS 与真实在线高程瓦片，不使用 Google Maps 或 Mapbox SDK。标签包含精选示例和 GeoNames 开放地名数据，并非完整或权威数据库；行政区边界仅作原型展示，未经标准地图审核。Android 应用由相同的网页构建产物生成，需要重新构建 APK 才能同步改动。

## 启动

需要 Node.js 20.19+ 或 22.12+。在项目目录运行：

```sh
npm install
npm run dev
```

服务固定监听 `0.0.0.0:4173`，本机访问 http://localhost:4173 ，同一局域网的设备可通过 `http://<这台电脑的局域网 IP>:4173` 访问。网络及防火墙需允许访问该端口。生产构建：`npm run build`；预览构建：`npm run preview`。

Chrome 只允许安全来源请求定位：在运行服务的电脑上可直接打开 `http://localhost:4173/`；从其他设备访问时，可另开终端执行 `npm run dev:https`，然后访问它打印的 `https://<局域网 IP>:4174/`。脚本使用 OpenSSL 创建仅用于本地开发的自签名证书，第一次访问须在浏览器证书警告中选择继续；仅在可信的本地网络中使用。不同设备可能要求将证书加入系统信任，正式部署应使用受设备信任的 HTTPS 证书。HTTP 页面不会弹出定位授权；需要检查 Chrome 网站权限和设备定位服务时，请在 HTTPS 页面点击定位按钮重试。

## 操作

- 触屏：单指拖动地图；双指捏合缩放、旋转；双指同时上下移动倾斜；三指左右拖动旋转。
- 触控板：双指上下滚动倾斜，双指左右滚动旋转，捏合缩放；按住鼠标或触控板拖动平移。
- 初始立体视角、定位失败后的全国视角和重置方向使用 60° 倾斜；主动定位时保留当前倾斜角，平面模式保持 0°。
- 从地图卡片向上滑动可打开倍率转盘，选 0× 切换平面、1× 和 10× 至 80× 切换立体；点击转盘中间的“取消”，或滑动至中间松开，可保持原倍率。从平面返回立体时恢复之前的倾斜角，保留平面期间调整的方向。普通点击仍打开地图设置。
- 鼠标：拖动平移，滚轮缩放；右键拖动可旋转和倾斜。地图左下角提供重置方向、放大、缩小和返回全国视角按钮。
- 浏览器通常不向网页暴露触控板的手指数；系统可能截获三指手势。不同设备的滚轮事件差异较大，触控板滚动与某些高精度鼠标滚轮可能无法完全区分。建议在目标设备上实测。
- 光照默认设为当天中午 12:00；点击“回到当前”后跟随当前时间并每分钟更新，时间采用北京时间（UTC+8）。地表根据各地经纬度计算太阳高度与日夜变化，结合坡面方向模拟明暗；卫星影像上也叠加此近似光影，并可通过“光影强度”调整，夜间使用环境光。光影使用相邻瓦片的边缘数据减少接缝，并尽量与地形采用相同数据层级；新视野的光影瓦片加载时会暂时隐藏整层光影，完成后统一显示；瓦片失败时保持隐藏并稍后重试。邻块加载超时会使用就近边缘，因此网络差时仍可能出现局部色差。为避免瓦片分块伪影，当前不模拟山体遮挡投影，也不能消除卫星影像拍摄时已有的阴影。可设置日期、时间和光影强度。
- “地图”卡片默认使用卫星影像，可切换地形设色、立体或平面，并保留高度倍率和鸟瞰细节设置。卫星数据加载失败时保持卫星模式并重试；也可手动切换至地形设色。“地图”卡片还提供自然、沙盘、山间远景预设，以及山体柔和度（默认 0%）和远景薄雾滑块；预设分别调整影像色调、柔和度和远景雾，不会更改视角和地形倍率。柔化只影响显示网格和光影，不改变地名原始海拔；薄雾随视距和角度变化，0% 可关闭。地图设置中的道路、铁路默认关闭，江河湖泊默认开启，均可分别开关；卫星影像和参考图层需要联网，使用系统内置字体。道路贴合地形表面，桥梁、隧道及 80× 地形高度属于视觉近似，不可用于导航。
- 点击左上角放大镜打开搜索，选择结果后自动收起；也可用 Ctrl/⌘ + K 打开、Esc 关闭。搜索支持地名、省、市、区县，以及十进制经纬度，例如“林芝市”“西安市长安区”或“116.4074,39.9042”。无标记的数字默认按经度、纬度顺序；也支持“纬度:39.9042 经度:116.4074”和“N 39.9042 E 116.4074”。坐标目标超出当前中国范围时会切换到全球显示。选择行政区时按需加载并高亮真实边界，再次点击同一标签或搜索结果取消选中。山峰和山脉目前只高亮地名点，尚无可用的山体范围边界。地图设置可控制中国范围、行政区边界及地名显示；市级、区县边界随缩放按需加载。
- 图层设置中的“仅显示选中行政区”可在选中省、市或区县后剥离其他区域；也可先打开开关再选择行政区。取消选择或关闭开关会恢复原地图。离线时仍使用已有全国概览数据；边界相交的瓦片需要裁切，而完全在区域外的卫星、高程及参考图层瓦片会尽量在调度前排除。数据加载量通常会减少，但切换范围需要重新处理部分瓦片，流畅度提升取决于视野和设备。
- 启动时尝试获取当前位置；获得授权并匹配到内置省级范围后，地图显示所在省级区域及蓝色位置标记。左下角定位按钮单击显示省份、双击显示市；图层设置里的“定位到区县”显示区县；直辖市的市级视图使用直辖市范围，细分边界缺失时显示可用的上一级。定位失败、拒绝授权或未匹配到示例中国范围时显示全国视角，可用定位按钮重试。位置使用内置边界在本地判断，不调用外部逆地理编码服务；位置精度和边界数据可能导致边界附近判断不准确。浏览器定位要求安全上下文：本机 `localhost` 或 HTTPS 可用，普通局域网 HTTP 页面通常不能使用定位。
- 地形高度倍率默认突出 40×，可使用滑块或“真实 1×、适中 20×、突出 40×、强烈 80×”预设。倍率仅影响视觉高度，不改变显示的真实海拔。较大倍率会显著扭曲地形比例。为减少范围边缘夸张的竖直拉伸，中国范围边缘的显示高程会渐变至海平面，不改变地名标注海拔；近处尽量维持稳定的瓦片级别，远处逐渐降低细节以控制加载量；层级切换和网络回退时仍可能出现局部跳变。接缝处启用有限长度的遮挡，极端倍率下仍可能看到接缝或边缘拉伸。地形卡片中的“鸟瞰地形细节”可选择标准、增强（默认）和精细：通过调整瓦片视觉尺寸，让同一视角使用更高层级的 DEM 和更密的地形网格。高程数据和地形网格采用一致的层级选择：近处使用比名义级别低一级的数据，远处逐渐降低细节，以减少旋转和倾斜时的切换。高倾角可能需要更多地形块；触屏设备使用较小的地图纹理以控制 GPU 内存，可能略微降低影像清晰度。当前仍没有新旧地形之间的网格渐变。每提高一档，理想情况下瓦片数最多约增加至四倍；实际数量受视野、裁切和数据源最大层级限制，加载时间、流量和设备内存占用也会增加。源数据细节有限，最高层级后不会继续变精细。

- 倾斜视角下，卫星影像按整个视野选择同一目标瓦片级别，避免近远处长期使用多级精度。为控制手机的请求数，视野特别大时会统一降低目标级别；加载中或网络失败时仍可能暂时回退到已缓存的低级瓦片。影像服务自身的不同拍摄批次、云层和拼接色差，以及远处地形纹理分辨率差异，不能通过统一瓦片级别完全消除。

- 顶部“布局”可选择自动、横屏或竖屏。搜索入口位于左上角，光照和地形控件默认折叠。
- 右上角“日照”卡片默认折叠，展开后可查看按地图中心和选定时间计算的太阳、月亮位置，滑动时间或恢复当前时间。中央代表地图朝向、上下代表高度角；地平线下的天体不显示。该示意为 360° 全景，不是相机视野内的透视投影。

## 数据与限制

- 高程地形：[Mapterhorn](https://mapterhorn.com/attribution)，Terrarium 格式瓦片；高程数据来源及署名请查看其归属说明。中国示例范围的 0–6 级全国概览已内置，`public/terrain-overview` 的 118 个瓦片合计 12,309,112 字节，小于 22 MB；范围外像素已清除，范围内高程保留原值。更高层级按需联网；在线请求失败时保留可用的父级数据，明确离线时放大概览瓦片。默认“中国范围”以外的数据需要联网。高程精度、数据许可和边界完整性需在正式部署前核实。
- `data/places.js` 为精选示例；`data/geonames-mountains.json` 包含从 GeoNames 提取的中文山脉、山体和山峰点，来源与文件校验见 `data/geonames-mountains.meta.json`。数据来自 [GeoNames](https://www.geonames.org/)，依据 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 使用；经过按名称、类型与示例陆地范围筛选并调整显示级别。它们是近似点，并非山脉范围，名称与海拔仍需核验。仅在 GeoNames 的 elevation 字段有值时显示海拔，不把 DEM 估算值当作测量高程。
- 省级边界及中国裁切范围来自 [China-GeoData](https://github.com/Supeset/China-GeoData)，该仓库声明 MIT 许可，附许可文本见 `data/CHINA-GEODATA-LICENSE`。其上游数据授权、地理完整性及标准地图适用性尚需独立核实；该数据不得视为经过审图的正式地图。
- 地市和区县名称索引来自 [Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China)，许可文本见 `data/ADMIN-INDEX-LICENSE`。索引覆盖大陆 31 个省级地区，不保证行政区划实时更新，也不包含港澳台的下级行政区。`data/admin-city-centers.json` 是从 DataV 边界数据提取的地市中心坐标，用于边界加载前显示标签；数据来源和使用许可需另行核实。
- 地市级边界与区县边界来自 [阿里云 DataV](https://datav.aliyun.com/portal/school/atlas/area_selector)，其中 2,824 个可匹配区县的边界按省分包，随网页代码按需加载。行政区名称索引中另有 154 个条目未能获取到匹配边界，多为开发区等，搜索仍可用，但无法保证高亮；数据也可能存在更新滞后。数据的授权、准确性和完整性需在正式使用前核实。
- 默认仅请求与示例中国陆地区域相交的高程瓦片并在本地裁切；由于服务按瓦片提供数据，边界相交的瓦片可能包含范围外的数据。小岛及海域覆盖取决于示例边界数据。
- 道路、铁路和水系使用 [OpenFreeMap](https://openfreemap.org/) 提供的 OpenStreetMap 矢量瓦片；卫星影像使用 [Esri World Imagery](https://www.arcgis.com/home/item.html?id=10df2279f9684e4a9f6a7f08febac2a9)，均按需联网，目前不提供离线包。地图使用及来源数据的许可、可用性和覆盖质量需在正式发布前核实。
- 暂未接入全量 OSM 地名、完整的地形数据处理流水线或区域离线下载。公开发布涉及地图内容审核及数据许可，需要另行核验。
- 地图需要支持 WebGL 的浏览器；详细地形、参考图层和卫星影像需要网络。国内网络访问第三方瓦片的效果请在实际网络中测试。

## 数据源配置

`src/terrain.js` 中的瓦片地址、裁切逻辑及 `src/main.js` 中的 `dem` 数据源构成高程输入。替换时需确认瓦片为 Terrarium 编码、跨域访问可用，并同步更新瓦片大小、最大缩放级别、署名与服务许可。处理流程与分层色带见 `src/terrain-processing.js`。实际生产应将配置抽离并使用有明确服务保障的瓦片源。

## Android 安装包与固定签名

Android 使用 Kotlin 和 Android WebView，网页构建产物随 APK 打包；新构建会内置全国概览瓦片，详细高程和在线参考图层仍需网络，设备的 WebView 需支持 WebGL。定位仅在前台申请系统近似位置权限，拒绝后可继续使用全国视图；WebView 仅允许应用内置页面请求定位。发布版 APK 通过 GitHub Actions 使用固定签名构建。支持横竖屏切换。应用 ID 为 `cn.peakmap.app`，Android 8.0（API 26）及以上可安装，实际兼容性取决于设备 WebView 与 GPU。

本地构建需要 Node.js、JDK 17、Android SDK 35，然后在项目根目录执行：

```sh
npm ci
npm test
npm run build
cd android
./gradlew assembleDebug
```

`assembleRelease` 必须设置 `ANDROID_KEYSTORE_PATH`、`ANDROID_STORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`，缺少时会失败，不会悄悄生成未签名的安装包。请安全备份签名密钥及密码；丢失后将无法用同一签名更新已安装的应用。不要把密钥或密码提交到仓库。

GitHub Actions 在推送到 main 或手动触发时构建经固定密钥签名的 release APK，验证签名并上传 `peakMapCN-signed-apk` 工件。签名所需的密钥和口令由仓库 Actions Secrets 提供，工件保留 30 天；它是供测试安装的构建，并不代表应用已完成上架或地图审核。

## 重新整理 GeoNames 山地名称

下载 GeoNames 的 `CN.zip` 和 `TW.zip`，安装 Python 3 与 `shapely>=2` 后执行 `python3 scripts/import_geonames.py CN.zip TW.zip`。脚本仅保留选定地貌类别、有中文名称且位于本项目示例边界内的记录，并输出 GeoNames 标识及来源文件校验值。生成物使用 GeoNames 的 CC BY 4.0 许可，来源数据本身可能存在错误、遗漏或命名差异。

全国离线体积的实测估算方法和限制见 [docs/offline-estimate.md](docs/offline-estimate.md)。

## 微信小程序发布前核查

本项目目前仍是网页和 Android 原型，不是可直接发布的微信小程序。数据服务所在地区、商业授权、地图审核、资质、备案与网页容器的注意事项见 [微信小程序发布前的数据来源与事项核查](docs/wechat-release-assessment.md)。
